# 请求入口与授权

先判断用户要选题、完整制作，还是只做某个阶段。栏目、品牌和目标工作区以本次用户材料及本地配置为准。

- “写一篇文章”：从适用栏目研究候选，说明读者收益、证据与首选理由，等待选题；计算机领域默认可从 AI、论文、就业各精选一题。
- 已选题、指定原文或明确授权自主选题直接写：连续完成研究、写作、审阅、配图、排版和真实移动预览，不重复索要选题确认。
- “只看本地”“不要上传”：保持 `delivery: local-only`，即使账号已配置也不能上传。
- “上传到我的公众号草稿箱”：先检查是使用者自己的配置和当前冻结版本，再在明确授权范围内调用带 `--confirm-upload` 的上传。
- “只审稿/只配图/只排版”：只处理被请求的阶段，并说明相应产物及尚未做的验收。
- 修改已有文章：先读该篇记录，保留旧版本；重跑受影响预览和审阅，不静默改写其他文章。

配置了密钥不等于授权每次上传；质量通过不等于用户批准；草稿上传成功不等于正式发布。
付费生图服务也须使用者自行启用和授权，不能沿用上游文档里的示范授权。

# Chuan 编辑版：完整文章的字图设计

默认视觉方向是有具体主体的封面与连续可读的正文，而不是组件展示页。
本版以 gzh Zen 的编辑语法为来源，重做内容装配。上游原件不改，适配在
`tools/wechat-publisher/wechat_publisher/gzh_layout.py` 的 ChuanEditorial 中，随本技能完整分发。
article.json 与 Markdown 一致使用 `gzh-chuan-editorial`。

默认提供整篇编辑排版；使用者可以选择其他主题。封面主体、构图和色彩按题材重新设计。

## 设计变量

2026-11-10 起，默认正文按已发布文章的字图节奏排。实现在 `gzh_layout.py` 的 ChuanEditorial。
开篇动效、章节标记、内容图背景和文末贴纸见 [排版动效](lsf-editorial.md)。

| 项目 | 当前默认 |
| --- | --- |
| 背景 / 正文 | 纯白 / #1a1a1a |
| 强调 | #5e8e3e，字重 400，不加下划线或底色 |
| 正文 | 系统无衬线，16px，字重 300，1.9 行高，字距 0.544px，左对齐 |
| 段距 | 段后 22px。开篇署名动图下方同样留 22px |
| 章节标题 | 22px，字重 500，1.4 行高，居中，标题下 18px |
| 章节标记 | 标题上方 42px 动态字母或数字 |
| 图注 | 11px，#aaa，居中，只写这张图是什么，不加句号 |
| 表格 | 按内容分列，不把每列撑成等宽。14px，表头字重 500、浅底 #f7f7f5，单元格字重 400，细线 #e4e4e4 |
| 代码 | 等宽字，保留原始空格与换行，无伪终端窗口 |
| 图片 | 正文内容图加背景、留白和 8px 圆角。封面、开篇署名、章节标记、文末贴纸不加 |

读者看到的正文不写「官方发布页」「模型文档」这类来源链接标签。来源留在 evidence.json。图注不写读图方法和制作过程。文末不写资料核对说明。

这是默认排版起点。封面的场景、色彩与视觉语言按本篇判断。

## 语义区块与映射

| 信息任务 | 书写入口 | 排版处理 |
| --- | --- | --- |
| 栏目刊头 | byline | 公众号正文不单独排刊头条 |
| 开篇判断 | 普通段落 | 与正文同一字号和段距，放在署名动图下面 |
| 正文论证 | 普通段落 | 左对齐，段后 22px |
| 章节转折 | h2 | 上方 42px 动态字母或数字，标题居中，标题下 18px |
| 次级论点 | h3/h4 | 18px，字重 500 |
| 重点短语 | strong/u | #5e8e3e，字重 400，不加下划线或底色 |
| 主视觉/证据图 | Markdown 图片 | 内容图加背景和 8px 圆角；封面、署名、章节标记、文末不加 |
| 图片说明 | image-note | 11px，只写这张图是什么 |
| 重要引文/判断 | blockquote | 与正文同一字号和段距 |
| 对照数据 | Markdown table | 按内容分列，浅色表头，窄屏检查长词 |
| 可执行示例 | 代码围栏 | 等宽字，逐字符保留源码 |
| 顺序/并列项 | ol/ul | 简洁列表，保留真实顺序起点 |
| 来源补注 | evidence.json | 不在正文里写来源链接标签 |
| 段落收束 | 普通段落 | 不强加总结卡，回到本篇实际问题 |
| 联系方式 | 可选文末贴纸 | 使用者用自己的二维码生成，默认可以省略 |

## 整篇骨架

刊头 → 一句导语 → 能表达主题的主视觉 → 读者问题与论点 → 解释/证据 → 连续论证 →
局限与具体行动 → 结尾 → 可选联系卡。主视觉和解释图放在它们有信息任务的位置，
可以删减区块；不要逐项集齐组件。论文原图附近保留读图说明，不能让漂亮概念图替代实验证据。

| 内容类型 | 优先编排 |
| --- | --- |
| 技术教程 | 痛点与预期 → 原理图/真实界面 → 步骤和代码 → 验证 → 边界 |
| 软件分享 | 使用场景 → 真实功能图 → 操作路径 → 对照 → 适用对象与限制 |
| 论文深读 | 研究问题 → 机制 → 原始结果图表 → 实验边界 → 工程启示 |
| 职业规划 | 具体处境 → 判断依据 → 路径比较 → 可执行行动 → 风险与反方 |
| 新闻评论 | 变化是什么 → 一手事实 → 影响 → 未确定部分 → 读者行动 |

## 视觉验收

先打开整篇 375/390 px，再看首屏、转折、证据图、表格、代码和结尾。
检查主体在缩略图是否仍可识别，首屏有没有先堆品牌装饰，连续正文是否被反复打断，
证据图是否太小，图片和注释是否分离，强调是否过量。确认字图关系后再登记视觉审阅。
上游 HTML 检查器无错误只是平台结构检查，不能代替这些判断，更不能代表用户已认可视觉。

测试中的合成夹具仅用于验证排版与版本约束，不是已发表文章或可上传的生产样稿。

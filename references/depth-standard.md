# 内容深度：从信息正确到读者真的理解

选题、起草和编辑复核时使用。必须结合 wewrite 原简报、增强策略与编辑标准。
这里增加判断依据，不用字数、术语密度、引用数量、图片数量或自评分冒充深度。

## 在简报里先决定要讲到哪里

除原版 audience / goal / thesis / sections 外，在 editor-brief.md 补充：

- **读者起点与终点**：哪些知识可假定，哪个困惑必须被解决。
- **解释主线**：从输入/前提到机制、现象或结果，中间最容易跳过的一步是什么。
- **贯穿对象**：任务、数据、公式实例、故障或设计决定；如何支撑核心判断。
- **证据和增量**：原文已经讲了什么，本篇增加什么；区分可运行教学案例、作者结果、本次实测。
- **反例和迁移**：哪个条件一改就会失败；读者如何识别条件变化。
- **章节关系**：所属路径、已有前置与后续；不适合系列时写独立篇及理由。

这些是研究问题，不是六个必须原样公开的标题。找不到贯穿对象时，判断是否该缩小问题；
观点和短动态可以采用证据对比而非硬编教学任务。

## 什么算把一件事讲透

**概念有对象。** 定义新术语后，立即在本篇任务里指出它对应哪个输入、状态、动作或代价。
能用通俗语言说明，却不把经验定律当物理规律。读者需要时再补术语与公式。

**推理没有跨步。** 例如“缓存更省钱”要解释复用了什么、命中何时成立、未命中的成本；
“岗位要求提高”要说明来自哪些岗位样本、哪些要求变化，能否排除样本变化。
不是在每段结尾加一句“这意味着”就算解释。

**案例能检验判断。** 展开一个有代表性的案例，给出必要条件和结果，胜过叠放许多一句话例子。
教学案例明确标为合成，能运行的就实际运行并留输入/输出；没有执行时不得写“实测”。
做不到完整实验时可展示原始案例或走通计算，不增加与题目无关的演示工作。

**取舍有因果和条件。** 说明方案为什么在这里有用、在哪个条件下改选别的方案。
最强反方进入论证，能改变结论，而非在结尾堆一段“仍有局限”的免责文字。

**读后能力可观察。** 教程能按步骤完成并识别失败；机制文能预测一个变化后的结果；
论文文能分清设计与证据；职业文能据个人约束选择并形成能力作品；项目文能理解或使用该项目。
不强迫每篇都送清单、模板和行动计划。

## 按形态选择深挖方式

| 形态 | 需要贯通的链条 | 最容易出现的假深度 |
| --- | --- | --- |
| guide | 起始环境/输入 → 操作与原因 → 可检查输出 → 失败分支 | 只有一段万能提示词；安装完成即宣布任务成功 |
| explainer | 具体困惑 → 最小机制 → 走通例子 → 改变条件后的推演 | 长术语表；把类比当真实结构；单一原因包打天下 |
| analysis | 明确判断 → 支持证据 → 强替代解释 → 条件化结论 | 反转标题后重复原文；只提醒“看情况” |
| paper-reading | 原问题与基线 → 方法选择 → 一个关键步骤 → 实验支持与未识别因素 | 摘要扩写；抄结果表；把相关差异写成组件因果 |
| project-case | 真实需求 → 当前方案与替代项 → 产物/反馈 → 取舍或迭代 | 功能与数量堆砌；没有材料的“我踩过坑” |
| update | 实质变化 → 证据/适用对象 → 必要行动 | 为凑长篇补行业空话，或冒称完整指南 |

论文的“关键步骤”可以是公式带入一个小例子、算法状态变化、架构中的一次请求，或实验设计的比较逻辑。
只有结论和边界，却不知道作者怎么做到的，仍未完成精读承诺。

## 审稿：用正文定位说明，而非只打分

在现有 `reviews/editorial.md` 增加“深度复核”，与该稿版本一起登记，不另建未绑定的批准。
按本篇承诺记录：

1. 承诺在正文何处兑现，必要的前置知识在哪里补上。
2. 最关键的解释段和案例；从材料到结论是否缺一步。
3. 本篇增量在哪里、证据/产物能否打开；哪些仍仅为作者报告或工程建议。
4. 最有力的反例或替代解释如何改变建议。
5. 读者能否处理一个稍有变化的任务；还可能在哪一步误解。

每项写具体段落/图表/产物定位和发现，不接受整段复制此表或仅写“通过”。
有明确缺口就修改正文、缩小承诺或补材料，再按 wewrite 五项重审。
案例代码的通过只能验证那段行为，不能替整篇的可读性、技术完整性和判断质量背书。

应退回的典型情况：

- 长文主要是发布页、摘要或功能清单的扩写，看不出阅读原文之外的收益。
- 建议没有对应机制或证据，换个工具/岗位名称还能原样成立。
- “我们实测/我发现”的关键证据不存在，或借用他人经历。
- 教程在关键操作、验收或常见失败处断开；论文在方法核心处跳到结果。
- 标题承诺完整指南，却只提供一个局部观察。

短动态只按其较窄承诺判断；不因篇幅短自动退回，也不靠写长获得放行。
在准确和有用的前提下保留作者判断，不能因担心犯错把全文写成“还要看、仍需观察”。

## 学习参考作者的方法

Oil Book 的具体研究记录留在项目 `references/content-upgrade-2026-11-05/benchmark-study.md`。
可迁移的是任务驱动、知识递进、展开案例和章节关系，不是其口头禅、第一人称经历、
插图或界面资产。参考作者的技术解释和效果判断也要回原始依据核查，不能整体视为事实权威。
页面存在、阅读时长标签、收费和视觉精致均不能证明读者学会了或经营成功。
